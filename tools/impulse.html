Physics — Wave Optics Notes
Huygen's Principle — key points to remember
Every point on a wavefront is a source of secondary wavelets that spread in all directions with the speed of the wave. The new wavefront is the envelope of these secondary wavelets at any later time. This principle explains reflection, refraction, and diffraction beautifully.
Young's Double Slit — fringe width formula
β = λD/d — where λ is wavelength, D is distance to screen, d is slit separation. Angular fringe width θ = λ/d. Both maxima and minima are equally spaced.
